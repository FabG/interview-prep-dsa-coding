## Task

Determine whether `s` reads identically forward and backward when letter case
is ignored and all characters other than letters and digits are disregarded.
Return `True` for a palindrome and `False` otherwise.

Digits count as alphanumeric characters. If no letters or digits remain,
the resulting empty sequence counts as a palindrome.

This description summarizes the linked LeetCode problem.

## Examples from LeetCode

| s | Expected result |
| --- | --- |
| `"A man, a plan, a canal: Panama"` | `True` |
| `"race a car"` | `False` |
| `" "` | `True` |

- String length is between 1 and 200,000 characters.

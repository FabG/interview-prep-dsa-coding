## Task

Given strings `s` and `t`, decide whether rearranging the letters of `s` can
produce `t`. Every letter must be used exactly as many times as it appears.
Return `True` if they are anagrams, otherwise `False`.

This description summarizes the linked LeetCode problem.

## Examples from LeetCode

| s | t | Expected result |
| --- | --- | --- |
| `"anagram"` | `"nagaram"` | `True` |
| `"rat"` | `"car"` | `False` |

## Input limits

- Each string has between 1 and 50,000 characters, inclusive.
- Both strings contain only lowercase English letters.
